# Milestone Playbook

Use this to turn vague freelance posts into safer project plans.

## AI chatbot projects

### Milestone 1: Discovery and test data

- Review existing code or support content
- Confirm FAQ sources and API documentation
- Define fallback behavior
- Agree on 10-20 test questions

### Milestone 2: MVP chatbot

- Build the chat API
- Add knowledge base matching
- Add basic web chat interface
- Return source and confidence metadata

### Milestone 3: Integration and handoff

- Connect approved APIs
- Add logging and setup documentation
- Run acceptance tests
- Record known limits and next steps

## Automation workflow projects

### Milestone 1: One workflow map

- Identify trigger, input, decision rules, output, and approval point
- Confirm target systems and API access
- Define failure handling

### Milestone 2: Working workflow

- Build intake adapter
- Add scoring or classification rules
- Generate payloads or drafts
- Keep human review before sending anything externally

### Milestone 3: Reliability

- Add retries
- Add logs
- Add run instructions
- Add alerts or summary reports

## Data extraction projects

### Milestone 1: Source validation

- Confirm the data source is allowed
- Document API/export access
- Define output schema
- Provide sample input and expected output

### Milestone 2: Extraction MVP

- Build source adapters
- Normalize records
- Validate required fields
- Export CSV or Excel-ready output

### Milestone 3: Scheduling and handoff

- Add scheduling
- Add error reports
- Add setup documentation
- Add maintenance notes
