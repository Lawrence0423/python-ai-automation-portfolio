# Client Questionnaire

Use this before accepting a project.

## Scope

1. What exact workflow or user problem should the first version solve?
2. What should be excluded from the first milestone?
3. What does a successful demo need to show?
4. Do you need deployment, documentation, tests, or ongoing maintenance?

## Access

1. Is there an existing codebase?
2. Is there API documentation?
3. Can you provide a sandbox account or test credentials?
4. Are there sample inputs and expected outputs?

## Data and AI use

1. Does the project use customer data, payment data, health data, or private business data?
2. Are AI tools allowed for development?
3. Can data be sent to OpenAI or another AI API?
4. Should sensitive data be masked before AI processing?

## Acceptance

1. What tests will you use to approve the work?
2. What performance target matters?
3. Who signs off on the milestone?
4. What happens if the source website, API, or business rule changes?

## Risk check

Do not accept without clarification if the client asks for:

- Paywall bypass
- Login bypass
- Mass unsolicited messaging
- Scraping that violates a platform's terms
- Fake reviews, fake accounts, or spam automation
- Handling sensitive data without clear permission
